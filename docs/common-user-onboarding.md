# Common User Onboarding

Cognition Store should be understandable to a user who does not write code.

## Plain-English Product Definition

Cognition Store is a business memory and decision-record system.

It helps users save important notes, AI-generated work, source evidence, decisions, risks, and lessons in one organized place. The goal is to make important work easier to review, prove, reuse, and explain later.

## Who It Is For

- founders tracking important business decisions
- consultants preparing client reports
- operations teams recording completed work and lessons learned
- compliance teams checking what evidence supported a recommendation
- researchers organizing notes, claims, and sources
- AI users who want a memory trail instead of scattered chats and files

## First-Run User Journey

1. Create an account.
2. Create a workspace.
3. Choose what the workspace is for: business, research, compliance, sales, project memory, or AI work log.
4. Paste notes or upload approved files.
5. Select a template.
6. Review the extracted evidence, decisions, risks, and lessons.
7. Save the memory record.
8. Export a report or share it with a reviewer.

## User-Friendly Labels

The SaaS interface should avoid heavy internal language where possible.

- Evidence item: Source note
- Claim: Key point
- Knowledge graph: Connection map
- Verdict: Review result
- Artifact: Saved record
- Simulation: Scenario review
- Approval gate: Human review required

## Core Screens

- Home dashboard: recent memory records, risks, exports, and templates
- New memory record: guided form for notes, file upload, category, and template
- Review result: sources, key points, decisions, risks, lessons, and approval flags
- Workspace settings: team, privacy, exports, API keys, and retention
- Reports: downloadable summaries and audit trails

## Commercial Readiness Rule

The common-user SaaS should be judged by one question:

Can a non-technical buyer understand the product, create a record, review the result, and export value within five minutes?
